# 虛構材料：訂單匯出功能規格節錄（節錄一）

> ⚠️ 這是 workshop 的**虛構**分析材料。內容為杜撰，不含任何客戶名稱、商標或聯絡資訊。
> 用途是貼給規格健檢專家分析。

## 3. 功能需求

### 3.1 訂單匯出

系統應該能讓使用者匯出訂單資料。匯出格式支援常見格式。匯出應該要快。

### 3.2 篩選條件

使用者可以依日期區間與客戶篩選。日期區間的上限視情況而定。

### 3.3 通知

匯出完成後通知相關人員。

### 3.4 權限

只有有權限的人可以匯出。

## 4. 非功能需求

| 項目   | 需求             |
| ------ | ---------------- |
| 效能   | 系統反應要即時   |
| 可用性 | 盡量不要中斷     |
| 安全性 | 依照公司政策辦理 |
| 相容性 | 支援主流瀏覽器   |

## 5. 交付清單

| 編號 | 交付項目 | 完成定義 | 負責人 | 期限    |
| ---- | -------- | -------- | ------ | ------- |
| D-01 | 匯出功能 | —        | —      | 第 6 週 |
| D-02 | 使用手冊 | —        | —      | 第 6 週 |
| D-03 | 測試報告 | —        | —      | 第 7 週 |
| D-04 | 上線     | —        | —      | 第 8 週 |

## 6. 驗收方式

由業務單位確認功能符合預期後簽核。

## 7. 假設與相依

- 假設既有的訂單資料庫可以直接查詢。
- 相依於通知服務（另案處理）。
